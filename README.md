# Yena Kim Portfolio

Static portfolio site for GitHub Pages.

## Deploy
1. Upload all files in this folder to the root of `rladPsks/rladPsks.github.io`.
2. Commit to the `main` branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. The site will be available at `https://rladPsks.github.io` after GitHub finishes deployment.
